# Leandro Alves // Portfolio

Portfólio pessoal estático em HTML, CSS e JavaScript.

## Publicar no GitHub + Vercel
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `script.js` para a raiz do repositório.
3. Na Vercel, escolha **Add New > Project** e importe o repositório.
4. Em Framework Preset, use **Other**. Não é necessário Build Command.
5. Clique em Deploy.

## Personalização
Edite os textos em `index.html`. Os comandos do terminal ficam no objeto `commands` em `script.js`.
